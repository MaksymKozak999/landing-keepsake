# Keepsake — landing page

Адаптивний односторінковий лендінг дизайн-агенції **Keepsake** за макетом Figma «Keepsake — Responsive» (Desktop 1280, Tablet 768, Mobile 375, Mobile menu open, UI states).

**Демо:**  https://maksymkozak999.github.io/landing-keepsake/

**Репозиторій:** https://github.com/MaksymKozak999/landing-keepsake

---

## Запуск

Відкрийте `index.html` у браузері або запустіть локальний сервер, наприклад розширенням Live Server у VS Code.
